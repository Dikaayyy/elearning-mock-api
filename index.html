E-Learning Mock API

Static JSON Mock API untuk take-home test aplikasi Flutter Student Simple E-Learning Platform (konsumsi via Dio, di-host di GitHub Pages).

Daftar Endpoint

  • GET /courses.json — Daftar ringkas semua course (5 course)
  • GET /courses/1.json — Dasar Pemrograman Flutter
  • GET /courses/2.json — Dart untuk Pemula
  • GET /courses/3.json — Dasar UI/UX untuk Aplikasi Mobile
  • GET /courses/4.json — State Management dengan Riverpod
  • GET /courses/5.json — Git dan GitHub untuk Developer Pemula
